| 1  | Apa fungsi `new Date()`?                                                  | `new Date()` digunakan untuk membuat Date Object yang berisi informasi tanggal dan waktu. Jika tidak diberi tanggal tertentu, maka akan mengambil tanggal dan waktu saat ini.                     |
| 2  | Mengapa bulan pada JavaScript dimulai dari `0`?                           | Karena JavaScript menggunakan index yang dimulai dari `0`. Jadi Januari = `0`, Februari = `1`, sampai Desember = `11`.                                                                            |
| 3  | Apa perbedaan `getDate()` dan `getDay()`?                                 | `getDate()` digunakan untuk mengambil tanggal dalam bulan (`1–31`), sedangkan `getDay()` digunakan untuk mengambil hari dalam minggu (`0–6`), dengan `0` = Minggu dan `6` = Sabtu.                |
| 4  | Apa fungsi `getTime()`?                                                   | `getTime()` digunakan untuk mendapatkan waktu dalam bentuk millisecond sejak 1 Januari 1970. Method ini dapat digunakan untuk menghitung selisih antara dua tanggal.                              |
| 5  | Mengapa kita perlu menggunakan `getMonth() + 1` ketika menampilkan bulan? | Karena `getMonth()` dimulai dari `0`, sehingga Januari menghasilkan `0`. Jika ingin menampilkan bulan dalam bentuk angka biasa, perlu ditambah `1`.                                               |
| 6  | Apa perbedaan Getter Method dan Setter Method?                            | Getter Method digunakan untuk mengambil nilai dari Date Object, seperti `getDate()` dan `getMonth()`. Setter Method digunakan untuk mengubah nilai tanggal, seperti `setDate()` dan `setMonth()`. |
| 7  | Apa kegunaan `toLocaleDateString()`?                                      | `toLocaleDateString()` digunakan untuk menampilkan tanggal sesuai format lokal atau negara tertentu, misalnya `"id-ID"` untuk format Indonesia.                                                   |
| 8  | Bagaimana cara menghitung selisih dua tanggal?                            | Gunakan `getTime()` pada kedua tanggal, kemudian kurangkan hasilnya. Setelah itu, bagi hasilnya dengan `1000 * 60 * 60 * 24` untuk mendapatkan selisih dalam hari.                                |
| 9  | Dalam aplikasi nyata, fitur apa saja yang dapat menggunakan Date Object?  | Date Object dapat digunakan untuk deadline tugas, jatuh tempo pembayaran, reminder, jadwal event, absensi, booking, menghitung umur, durasi, dan menampilkan waktu aktivitas pengguna.            |
